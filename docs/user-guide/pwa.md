# PWA 安装指南

将刷题助手添加到主屏幕，像原生 App 一样使用。

## 什么是 PWA？

PWA（Progressive Web App）是一种网页应用技术，让网页可以：

- 像原生 App 一样从主屏幕启动
- 全屏运行，没有浏览器地址栏
- 离线访问（部分功能）
- 接收推送通知（需支持）

## iOS / iPadOS 安装

### 步骤

1. 用 **Safari** 打开刷题助手网站
2. 点击底部的"分享"按钮

   ![分享按钮](./images/ios-share.png)

3. 在弹出的菜单中，向下滑动找到"添加到主屏幕"

   ![添加到主屏幕](./images/ios-add-home.png)

4. 点击"添加"
5. 主屏幕出现"刷题助手"图标

### 使用

- 点击主屏幕图标即可启动
- 全屏运行，没有浏览器地址栏
- 体验接近原生 App

### 注意事项

- 必须使用 **Safari** 浏览器
- Chrome、Firefox 等 iOS 浏览器不支持此功能

## Android 安装

### Chrome 浏览器

1. 用 Chrome 打开刷题助手网站
2. 点击右上角菜单（三个点）
3. 选择"添加到主屏幕"或"安装应用"
4. 确认安装

### 其他浏览器

大部分 Android 浏览器都支持类似功能，操作类似。

## 桌面浏览器安装

### Chrome / Edge

1. 打开刷题助手网站
2. 地址栏右侧会出现"安装"图标（⊕）
3. 点击安装
4. 应用会以独立窗口运行

### 手动安装

1. 点击右上角菜单
2. 选择"更多工具" → "创建快捷方式"
3. 勾选"作为窗口打开"
4. 点击"创建"

## 离线使用

安装 PWA 后，应用可以离线访问：

- 已缓存的页面可以正常访问
- 题目数据存储在本地，无需网络
- 首次加载后即可离线使用

### 离线限制

以下功能需要网络：

- 首次访问网站
- 导入在线题库
- 更新应用版本

## 更新应用

PWA 会自动更新，无需手动操作：

1. 访问网站时自动检查更新
2. 更新会在后台下载
3. 下次启动时使用新版本

### 强制更新

如果更新不及时，可以：

1. 清除浏览器缓存
2. 重新访问网站

## 卸载

### iOS / iPadOS

1. 长按主屏幕图标
2. 点击"删除 App"
3. 确认删除

**注意**：这只是删除了快捷方式，不会清除应用数据。数据仍保留在 Safari 中。

### Android

1. 长按主屏幕图标
2. 拖动到"卸载"区域
3. 确认卸载

### 桌面

1. 右键点击应用图标
2. 选择"卸载"

## 常见问题

### Q: iOS 上找不到"添加到主屏幕"选项？

确保：
- 使用的是 Safari 浏览器
- 不是在隐私/无痕模式下

### Q: 安装后数据会同步吗？

不会。PWA 的数据存储在本地，不同设备之间不互通。

### Q: 安装后占用多少空间？

应用本身很小（约 1-2MB），题目数据根据题库大小而定。

### Q: 为什么要用 PWA 而不是原生 App？

- 无需上架应用商店
- 无需审核，更新快
- 跨平台，一套代码
- 开源项目资源有限
