# 快速开始

5 分钟上手刷题助手。

## 访问应用

### 方式一：在线访问

直接打开网站即可使用（待部署）。

### 方式二：本地运行

```bash
# 克隆仓库
git clone https://github.com/taichilei/my-quiz.git

# 进入 web 目录
cd my-quiz/web

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

浏览器访问 `http://localhost:5173`

## 界面介绍

应用底部有四个标签页：

| 标签 | 功能 |
|------|------|
| **刷题** | 随机刷题，答题后显示答案解析 |
| **题库** | 查看所有题目列表 |
| **添加** | 手动添加新题目 |
| **设置** | 导入导出、数据管理 |

## 开始刷题

1. 打开应用，默认进入"刷题"页面
2. 点击选项选择答案
3. 点击"确认答案"（多选题）或直接选择（单选题）
4. 查看答案解析，点击"下一题"继续

## 导入题库

1. 进入"设置"页面
2. 点击"选择文件"，选择 JSON 格式的题库文件
3. 导入成功后，题目自动添加到题库

题库格式参考：[题目格式规范](../question-schema.md)

## 添加到主屏幕（推荐）

在 iPad/iPhone 上可以将应用添加到主屏幕，像原生 App 一样使用：

1. 用 Safari 打开网站
2. 点击"分享"按钮（方框带向上箭头）
3. 选择"添加到主屏幕"
4. 主屏幕出现"刷题助手"图标

详细说明：[PWA 安装](./pwa.md)

## 数据说明

所有数据存储在浏览器本地（IndexedDB），不会上传到服务器。

- 换浏览器/设备：数据不互通
- 清除浏览器数据：题目会丢失
- 建议定期导出备份
