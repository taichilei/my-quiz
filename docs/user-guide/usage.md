# 使用指南

详细介绍刷题助手的各项功能。

## 刷题模式

### 随机刷题

进入"刷题"页面，题目随机排列，适合模拟考试场景。

**操作流程：**

1. 阅读题目内容
2. 选择答案
   - **单选题**：直接点击选项
   - **多选题**：点击多个选项后，点击"确认答案"
   - **判断题**：点击"正确"或"错误"
3. 查看答案解析
4. 点击"下一题"继续

**快捷操作：**

- 不确定答案时，点击"我不会，看答案"直接查看解析
- 答题完成后显示正确率和答题统计

### 题目类型支持

| 类型 | 说明 | 答案格式 |
|------|------|----------|
| 单选题 | 四选一 | 点击选项直接作答 |
| 多选题 | 多选 | 选择后点击"确认答案" |
| 判断题 | 正确/错误 | 点击选项直接作答 |

## 题库管理

### 查看题目列表

进入"题库"页面，可以看到所有题目的列表。

**题目卡片信息：**

- 题目类型标签（单选/多选/判断）
- 题目内容
- 选项（选择题）
- 答案
- 解析
- 难度等级
- 标签
- 来源考试

**操作：**

- 点击"删除"可以删除题目

### 手动添加题目

进入"添加"页面，可以手动添加新题目。

**必填信息：**

| 字段 | 说明 |
|------|------|
| 题目类型 | 单选题/多选题/判断题 |
| 题目内容 | 题干 |
| 选项 | 选择题必填，至少 2 个选项 |
| 答案 | 正确答案 |

**可选信息：**

| 字段 | 说明 |
|------|------|
| 解析 | 答案解释 |
| 难度 | 简单/中等/困难 |
| 标签 | 分类标签，逗号分隔 |
| 考试信息 | 来源考试、部分、题号 |

**考试信息填写示例：**

```
考试名称：2018年上半年江苏省事业单位招聘考试
年份：2018
科目：综合知识和能力素质
部分：客观题
题号：1
```

## 设置页面

### 导入题库

支持导入 JSON 格式的题库文件。

**操作步骤：**

1. 点击"选择文件"
2. 选择 `.json` 格式的题库文件
3. 等待导入完成
4. 查看导入结果

**支持的格式：**

- 题目数组：`[ {题目1}, {题目2}, ... ]`
- 题库格式：`{ "metadata": {...}, "questions": [...] }`

### 导出备份

点击"导出题目"，将所有题目导出为 JSON 文件，可用于：

- 备份数据
- 迁移到其他设备
- 分享给他人

### 清空数据

点击"清空"可以删除所有题目。

⚠️ **注意**：此操作不可恢复，请先导出备份！

## 常见问题

### Q: 数据会丢失吗？

数据存储在浏览器本地，以下情况会丢失：

- 清除浏览器数据
- 使用隐私模式
- 卸载浏览器

**建议**：定期导出备份。

### Q: 如何在多设备同步？

目前不支持自动同步，可以通过"导出/导入"手动迁移数据。

### Q: 支持 Safari 吗？

支持。推荐使用 Safari 的"添加到主屏幕"功能，体验更佳。

### Q: 题库在哪里找？

项目提供了示例题库，位于 `question-banks/` 目录。你也可以自己整理题库，参考[题目格式规范](../question-schema.md)。
