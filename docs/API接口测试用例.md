# API 接口测试用例

本文档包含 My-Quiz 后端所有 API 接口的详细测试用例。

---

## 一、认证接口（公开，无需 Token）

### 1.1 用户注册

| 用例编号 | 测试场景 | 请求参数 | 预期状态码 | 预期结果 |
|---------|---------|---------|-----------|---------|
| AUTH-001 | 正常注册（必填字段） | `{username, password}` | 201 | 返回 token 和用户信息 |
| AUTH-002 | 正常注册（带邮箱） | `{username, password, email}` | 201 | 返回 token 和用户信息 |
| AUTH-003 | 用户名为空 | `{username: "", password}` | 400 | 返回错误信息 |
| AUTH-004 | 密码为空 | `{username, password: ""}` | 400 | 返回错误信息 |
| AUTH-005 | 用户名重复 | 第二次使用相同用户名 | 409 | 返回 "Username already exists" |
| AUTH-006 | 请求体为空 | 无请求体 | 400 | 返回错误信息 |

---

### 1.2 用户登录

| 用例编号 | 测试场景 | 请求参数 | 预期状态码 | 预期结果 |
|---------|---------|---------|-----------|---------|
| AUTH-007 | 正常登录 | `{username, password}` | 200 | 返回 token 和用户信息 |
| AUTH-008 | 密码错误 | 正确用户名 + 错误密码 | 401 | 返回 "Invalid username or password" |
| AUTH-009 | 用户不存在 | 未注册的用户名 | 401 | 返回 "Invalid username or password" |
| AUTH-010 | 用户名为空 | `{username: "", password}` | 400 | 返回错误信息 |
| AUTH-011 | 密码为空 | `{username, password: ""}` | 400 | 返回错误信息 |

---

## 二、用户信息接口（受保护，需 Token）

### 2.1 获取当前用户信息

| 用例编号 | 测试场景 | 请求头 | 预期状态码 | 预期结果 |
|---------|---------|--------|-----------|---------|
| USER-001 | 带有效 token | `Authorization: Bearer <valid_token>` | 200 | 返回当前用户信息 |
| USER-002 | 不带 token | 无 Authorization header | 401 | 返回 "Authorization header required" |
| USER-003 | token 格式错误 | `Authorization: <token>`（缺少 Bearer） | 401 | 返回 "Invalid authorization format" |
| USER-004 | token 无效 | `Authorization: Bearer invalid_token` | 401 | 返回 "Invalid or expired token" |
| USER-005 | token 过期 | 使用过期的 token | 401 | 返回 "Invalid or expired token" |

---

### 2.2 更新用户信息

| 用例编号 | 测试场景 | 请求参数 | 预期状态码 | 预期结果 |
|---------|---------|---------|-----------|---------|
| USER-006 | 正常更新邮箱 | `{email: "new@example.com"}` + 有效 token | 200 | 返回更新后的用户信息 |
| USER-007 | 清空邮箱 | `{email: ""}` + 有效 token | 200 | 邮箱被清空 |
| USER-008 | 不带 token 更新 | 无 token | 401 | 认证失败 |

## 八、冒烟测试（快速验证）

### 核心流程测试

| 步骤 | 操作 | 预期结果 |
|-----|------|---------|
| 1 | 启动后端服务 | 服务正常启动，端口 8080 |
| 2 | 访问健康检查 `GET /health` | 返回 `{"status": "ok"}` |
| 3 | 注册新用户 | 201，获取 token |
| 4 | 使用 token 获取用户信息 | 200，返回用户信息 |
| 5 | 使用 token 获取题目列表 | 200，返回题目数组 |
| 6 | 使用 token 获取考试列表 | 200，返回考试数组 |
| 7 | 不带 token 访问题目 | 401，认证失败 |
